## 🌐 GitHub Codespaces Setup (Recommended for Cloud)

### What is it?
A fully configured development environment in the cloud with all languages pre-installed.

### How to Start
1. Go to your GitHub repository: https://github.com/yourusername/nuclear-crawler-hybrid
2. Click **Code** → **Codespaces** → **Create codespace on main**
3. Wait 2-3 minutes for environment to initialize
4. **That's it!** Everything is pre-installed.

### First Commands in Codespace
```bash
# Validate everything is working
bash validate-environment.sh

# See quick start options
bash quick-start.sh

# Or read the post-setup guide
cat POST_CODESPACE_CONFIG.md
```

### Codespace Files
| File | Purpose | When to Use |
|------|---------|------------|
| `.devcontainer/devcontainer.json` | Defines the Codespace environment | Automatically used when Codespace starts |
| `.devcontainer/README.md` | Detailed Codespace documentation | Read after Codespace starts |
| `CODESPACE_SETUP.md` | Quick Codespace setup guide | First time users |
| `POST_CODESPACE_CONFIG.md` | Configuration after Codespace creation | After Codespace starts |

### Codespace Estimated Costs
- **Free tier**: 60 hours/month on 2-core machine
- **Cost**: ~$0.36/hour for more powerful machines
- **Storage**: 15GB included per month

## 💻 Local Machine Setup

### Supported Systems
- ✅ Ubuntu 20.04+
- ✅ Ubuntu 22.04+
- ✅ Debian 11+
- ✅ macOS 12+ (with slight modifications)
- ✅ Windows WSL2 + Ubuntu

### Quick Start (1 command)
```bash
bash local-setup.sh
```

This will:
1. Update system packages
2. Install Chapel 2.7 compiler
3. Install Rust with cargo
4. Install Python 3.11 with 100+ packages
5. Install Node.js, Java, Go
6. Configure development tools
7. Validate everything works

**Time required**: ~30 minutes (first time)
**Disk space**: ~2GB
**Prerequisites**: sudo access

### Local Setup Files
| File | Purpose |
|------|---------|
| `local-setup.sh` | Automates local installation |
| `validate-environment.sh` | Checks if everything is installed |
| `quick-start.sh` | Interactive menu for common tasks |
| `Makefile` | Commands for building, testing, running |

### Manual Local Setup (if you prefer)
```bash
# Just the important ones:
1. Install Chapel: https://chapel-lang.org/docs/usingchapel/installing.html
2. Install Rust: https://rustup.rs/
3. Install Python 3.11+
4. Install Node.js: https://nodejs.org/
5. Install Java 21: https://www.oracle.com/java/technologies/downloads/

# Then:
pip3 install -r requirements.txt
```

## 🆘 Troubleshooting

### "Command not found" errors
```bash
# Rerun validation to see what's missing
bash validate-environment.sh

# Install missing component
bash local-setup.sh  # (or recreate Codespace)
```

### Python import errors
```bash
pip3 install --upgrade package_name
pip3 install -r requirements.txt
```

### Codespace storage full
```bash
make clean     # Remove build artifacts
git gc         # Cleanup git history
```

### Codespace pauses after inactivity
- Codespace pauses after 30 minutes without activity
- Just click in editor or terminal to wake it up
- No data is lost
